## Visual and interaction system

Ivory #F4F2ED, ink #172129, deep blue #2351BA. Source Sans 3 provides the main
hierarchy; Fraunces italic accents the positioning phrase and the colophon.
Generous editorial spacing, ruled case articles, strong typographic hierarchy,
and one dark closing section. Identity remains the person's name.

Five architectural planes, metal connectors and a central cube form a procedural
Three.js sculpture. Entrance assembly and restrained pointer motion settle to
zero rendering. In Approach, the selected field lifts its corresponding plane.
The sculpture is decorative and never carries required text or controls.

Mobile/touch, data saving, reduced motion and failed WebGL use the static art.
The server sends all brief content. JavaScript adds radio selection and hides
unselected panels only after hydration. All links remain ordinary anchors.

## Public agent access

Use the evaluator's Content Site profile: real robots/sitemap, discovery headers,
Markdown negotiation, bot rules and content preferences. /index.md contains the
complete authored portfolio; /llms.txt links to public sources. HTML and Markdown
share content.ts. / negotiates explicit preferred text/markdown and keeps normal
browser HTML/RSC intact. Markdown negotiation is uncached to avoid CDN mixing.

Content-Signal permits search and AI input, and declines AI training. These are
preferences, not technical enforcement. DNS-AID, OAuth, MCP, commerce and skill
catalogs are not product capabilities and are not fabricated for a score.
