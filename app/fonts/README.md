# OG image fonts

Latin subsets used only by `app/opengraph-image.tsx`. The site itself loads
the same families through `next/font`.

- **Fraunces** (SIL OFL 1.1) — Undercase Type. Variable files pin optical
  size, soft, and wonk at the named Regular / SemiBold instances satori can
  read.
- **Source Sans 3** is loaded on the page via `next/font`. The share card
  uses Fraunces for the headline and a system sans for the chrome.
