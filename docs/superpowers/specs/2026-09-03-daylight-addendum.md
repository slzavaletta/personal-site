# Daylight — addendum to the living editorial specification

Date: 2026-09-03

Status: Implemented (type-only hero; portrait deferred).

Supersedes the visual system, motion grammar, page structure and signature
elements of `2026-09-02-living-editorial-addendum.md`. Facts,
`ROLE_TRANSITION`, security, accessibility floors and the living layer
(clock, last push, ISR, brief semantics) stand.

Rationale lives in
`docs/superpowers/plans/2026-09-03-daylight-redesign-plan.md`.

## Signature elements

1. **Quiet type.** The name in the header, in Andada Pro, at body size. The
   hero statement in Andada italic at a reading size. No stacked all-caps
   billboard, no boxed SLZ, no width-axis motion.
2. **City light.** `data-hour` on `<html>` (0–23, Buenos Aires) shifts
   paper's LCH. Dark is a pinned or system scheme. Reduced motion snaps.
3. **The brief as a document.** Five fields remain a radio group with
   roving focus. The selected field expands in place, on paper.

## Removed

Kinetic name, vermilion, inverse band, 01/02/03 dossiers, "Result signal",
five-column evidence index, diamond timeline, four-column tool marketing
grid, Archivo / Source Sans / IBM Plex Mono.
